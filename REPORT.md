# Brief Report — AI Math Differentiator

## Purpose
This project demonstrates AI-supported differentiated learning through a web application focused on solving quadratic equations. Instead of giving every learner the same task, the application adapts the task and guidance to three levels: Foundation, Standard, and Advanced.

## AI prompts
The AI receives a level-specific instruction. The Foundation prompt requests simple numbers, familiar context, explicit scaffolding, a direct hint, and a complete solution. The Standard prompt requests a grade-level curriculum problem, moderate scaffolding, a useful hint, and a complete solution. The Advanced prompt requests a multi-step or real-world problem, greater mathematical reasoning, a strategic hint, and less direct support.

## How differentiation is achieved
Differentiation is implemented through four dimensions: task complexity, numerical complexity, amount of scaffolding, and type of guidance. Foundation learners receive more support and smaller steps. Standard learners solve a typical curriculum problem. Advanced learners work with multi-step applications and greater independence. The interface also provides instant AI-assisted hints, explanations, and solutions.

## Conclusion
The application shows how one mathematical concept can remain constant while the learning experience changes according to learner readiness. AI can therefore support personalized practice, while teachers can still review the generated tasks for mathematical correctness and appropriateness.
